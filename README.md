# SpeechAI API

Новая API для интеграции с 1С и загрузки консультаций через веб-интерфейс.

## Что есть сейчас

- `GET /api/integration/1c` - проверить и нормализовать данные из 1С через query params
- `POST /api/integration/1c/normalize` - проверить и нормализовать JSON-пayload из 1С
- Блок для администратора на главной странице для теста передачи врача и пациента
- Загрузка консультации с сохранением данных 1С вместе с записью

## Тестовый сценарий

1. Войти как `admin`.
2. Открыть главную страницу.
3. Заполнить блок `Данные из 1С`.
4. Загрузить аудио.
5. Проверить, что данные врача и пациента сохранились у консультации.

## Формат данных 1С

### Врач

- `Код` - до 9 символов
- `ФИО` - до 70 символов
- `Должность` - до 70 символов
- `Категория врача` - до 35 символов

### Пациент

- `Код` - до 9 символов
- `ФИО` - до 70 символов
- `Дата рождения`
- `Возраст` - до 2 цифр
- `Пол` - `М` или `Ж`
- `Телефон` - несколько значений допускается
- `Почта` - несколько значений допускается

## Передача через ссылку

Данные можно передать через query params на `GET /api/integration/1c`:

```text
/api/integration/1c?consultation_date=10/06/2026&doctor_code=123&doctor_full_name=Иванов%20И.И.&patient_full_name=Петров%20А.А.
```

Поддерживаются параметры:

- `consultation_date`
- `doctor_code`
- `doctor_full_name`
- `doctor_position`
- `doctor_category`
- `patient_code`
- `patient_full_name`
- `patient_birth_date`
- `patient_age`
- `patient_gender`
- `patient_phones`
- `patient_emails`

Все даты передаются и возвращаются в формате `дд/мм/гггг`.
Для `patient_phones` и `patient_emails` можно передавать значения через `;` или перенос строки.
