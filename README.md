# SpeechAI 1.2

MVP для анализа стоматологических консультаций: загрузка MP3, транскрипция, оценка врача по 6 этапам и просмотр результата на простом сайте.

## Что есть сейчас

- Вход в админку и для врачей
- Вкладка `Пользователи` для создания, редактирования и удаления учёток
- Список консультаций и карточка записи
- Загрузка аудиозаписей
- Передача данных из 1С через ссылку
- Вход врача по ссылке с автоматической авторизацией
- У врача виден редактируемый блок `Данные из 1С`; у админа его нет
- Вид консультации: первичная взрослая или повторная взрослая
- Разные промпты оценки для первичного и повторного визита

## Как работать

1. Откройте сайт и войдите как `admin`.
2. Перейдите во вкладку `Пользователи`.
3. При необходимости создайте нового пользователя, поменяйте пароль или получите ссылку входа.
4. Для врача используйте ссылку вида `GET /api/integration/link-doctor?...`.
5. Врач автоматически входит в свою учётную запись, получает данные врача и пациента из ссылки, видит и может править блок `Данные из 1С`, дата выставляется текущей.
6. Загрузите запись и дождитесь обработки.

## Вход врача по ссылке

Администратор получает готовую ссылку входа врача в панели пользователей.

```text
/api/integration/link-doctor?token=...
```

Эту ссылку удобно вставлять в 1С. При переходе врач автоматически авторизуется и получает параметры в форме.

## 1С API

- `GET /api/integration/1c` - JSON с данными из 1С
- `POST /api/integration/1c/normalize` - JSON-валидация
- `GET /api/integration/1c-link` - открыть страницу админа с автозаполнением
- `GET /api/integration/link-doctor` - открыть страницу врача, залогинить и передать данные

### Параметры ссылки `link-doctor`

- Дата консультации - `consultation_date`
- Вид консультации - `consultation_type` (`primary_adult` или `repeat_adult`)
- Подразделение клиники - `clinic_division`
- Код врача - `doctor_code`
- ФИО врача - `doctor_full_name`
- Должность врача - `doctor_position`
- Категория врача - `doctor_category`
- Код пациента - `patient_code`
- ФИО пациента - `patient_full_name`
- Дата рождения пациента - `patient_birth_date`
- Возраст пациента - `patient_age`
- Пол пациента - `patient_gender`
- Телефоны пациента - `patient_phones`
- Почты пациента - `patient_emails`

## Формат данных

- Код врача и пациента - до 9 символов
- ФИО врача и пациента - до 70 символов
- Должность врача - до 70 символов
- Категория врача - до 35 символов
- Возраст - до 2 цифр
- Пол - `М` или `Ж`
- Даты - `дд/мм/гггг`
- Вид консультации - `primary_adult` или `repeat_adult`
- Обязательные поля записи: дата, вид консультации, подразделение, ФИО врача, ФИО пациента
- Телефон и почта пациента могут быть множественными

## Локальный запуск

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd ..
cp .env.example .env

cd backend
uvicorn app.main:app --reload --port 8000
```

## Docker

```bash
cp .env.example .env
mkdir -p volumes/data
docker compose up -d
```

cd /opt/speechai
