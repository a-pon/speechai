# SpeechAI 1.1

MVP для анализа стоматологических консультаций: загрузка MP3, транскрипция, оценка врача по 6 этапам и просмотр результата на простом сайте.

## Что есть сейчас

- Вход в админку и для врачей
- Вкладка `Пользователи` для создания, редактирования и удаления учёток
- Список консультаций и карточка записи
- Загрузка аудиозаписей
- Передача данных из 1С через ссылку
- Вход врача по ссылке с автоматической авторизацией
- У врача виден редактируемый блок `Данные из 1С`; у админа его нет

## Как работать

1. Откройте сайт и войдите как `admin`.
2. Перейдите во вкладку `Пользователи`.
3. При необходимости создайте нового пользователя, поменяйте пароль или получите ссылку входа.
4. Для врача используйте ссылку вида `GET /api/integration/doctor-entry?...`.
5. Врач автоматически входит в свою учётную запись, получает данные врача и пациента из ссылки, видит и может править блок `Данные из 1С`, дата выставляется текущей.
6. Загрузите запись и дождитесь обработки.

## Вход врача по ссылке

Администратор может получить ссылку входа врача через:

```text
/api/auth/doctor-link?username=Кухтарская%20Татьяна
```

Эта ссылка удобна для вставки в 1С. Для полного сценария из 1С используйте:

```text
/api/integration/doctor-entry?username=Кухтарская%20Татьяна&doctor_full_name=Кухтарская%20Татьяна&patient_full_name=Петров%20А.А.
```

## 1С API

- `GET /api/integration/1c` - JSON с данными из 1С
- `POST /api/integration/1c/normalize` - JSON-валидация
- `GET /api/integration/1c-link` - открыть страницу админа с автозаполнением
- `GET /api/integration/doctor-entry` - открыть страницу врача, залогинить и передать данные

## Формат данных

- Код врача и пациента - до 9 символов
- ФИО врача и пациента - до 70 символов
- Должность врача - до 70 символов
- Категория врача - до 35 символов
- Возраст - до 2 цифр
- Пол - `М` или `Ж`
- Даты - `дд/мм/гггг`
- Телефон и почта пациента могут быть множественными

## Локальный запуск

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cd ..
cp .env.example .env

cd backend
uvicorn app.main:app --reload --port 8000
```

## Docker

```bash
cp .env.example .env
mkdir -p volumes/data
docker compose up -d
```
